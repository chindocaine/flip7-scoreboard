Other details

  • Persistence: every action (including the not-yet-confirmed selections of the current turn, open dialogs, language, theme) is written to localStorage; a reload restores the exact screen.
  • Layout switch: tablet layout at ≥ ~900px width, phone layout below. The turn screen needs no scrolling.
  • Scoring (automatic): sum of numbers → ×2 doubles the number total → + modifiers → +15 for 7 different numbers. Busted = 0. Frozen/stayed bank their current total.
  • Tech plan: Vite + Svelte static PWA, served by nginx in a small Docker image on port 8080, no backend.
